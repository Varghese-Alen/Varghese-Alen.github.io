## What I work on

- **Design engineering:** 3D CAD for mechanisms, machines and products.
- **Simulation:** FEA, CFD and multibody dynamics.
- **Mechatronics and robotics:** machines where mechanics, motors and control work as one.
- **Project management:** from the first brief to delivery.
